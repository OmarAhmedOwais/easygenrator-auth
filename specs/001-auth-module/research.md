# Research 001: options and decisions

Short records of the choices made while planning. Long-lived ones are promoted to ADRs in
[`docs/adr`](../../docs/adr/README.md).

| ID   | Question           | Options                                                            | Decision                                                                                                                 | Why                                                                                     |
| ---- | ------------------ | ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------- |
| R-1  | Frontend framework | React, Vue                                                         | **React 19**                                                                                                             | Same stack as the reference projects (bewafra). Largest ecosystem for forms and testing |
| R-2  | Build tool         | Vite, Next.js                                                      | **Vite**                                                                                                                 | Pure SPA, no SSR needed. Instant dev server                                             |
| R-3  | Forms & validation | Formik + Yup, RHF + zod                                            | **react-hook-form + zod**                                                                                                | Typed schemas, minimal re-renders, resolver ecosystem                                   |
| R-4  | Routing            | React Router, TanStack Router                                      | **React Router v7**                                                                                                      | Layout routes make guards trivial. Well known to reviewers                              |
| R-5  | UI                 | MUI, Chakra, Tailwind + Radix (shadcn)                             | **Tailwind v4 + Radix primitives**                                                                                       | Small bundle, accessible, full design control                                           |
| R-6  | ODM                | Mongoose, Typegoose, Prisma                                        | **Mongoose** ([ADR-0002](../../docs/adr/0002-mongodb-with-mongoose.md))                                                  | First-class `@nestjs/mongoose`, schemas + indexes                                       |
| R-7  | Password hashing   | bcrypt, scrypt, argon2id                                           | **argon2id** ([ADR-0005](../../docs/adr/0005-argon2id-password-hashing.md))                                              | OWASP first choice. No 72-byte truncation                                               |
| R-8  | Token transport    | localStorage JWT, cookie-only session, memory + refresh cookie     | **memory + httpOnly refresh cookie** ([ADR-0003](../../docs/adr/0003-token-strategy-access-in-memory-refresh-cookie.md)) | Resists XSS token theft and CSRF                                                        |
| R-9  | Architecture depth | Plain service + model, hexagonal port/adapter, full CQRS           | **Port/adapter, no CQRS** ([ADR-0004](../../docs/adr/0004-repository-port-and-adapters.md))                              | Testability without ceremony                                                            |
| R-10 | Logging            | Nest Logger, winston, pino                                         | **nestjs-pino**                                                                                                          | Fast JSON logs, request ids, redaction built in                                         |
| R-11 | Env validation     | none, class-validator, Joi, zod                                    | **Joi** via `ConfigModule.validate`                                                                                      | Mature, readable schema with defaults/coercion                                          |
| R-12 | API test DB        | mongodb-memory-server, mocks, in-memory adapter + real Mongo in CI | **In-memory adapter + real MongoDB in CI**                                                                               | Binary download blocked in the sandbox. Exercising the real adapter in CI beats mocks   |
| R-13 | NestJS version     | 11 (CJS), 12 (ESM)                                                 | **12** ([ADR-0006](../../docs/adr/0006-nestjs-12-native-esm-and-vitest.md))                                              | Latest major, official ESM starter with Vitest                                          |

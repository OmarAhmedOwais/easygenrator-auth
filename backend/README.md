# Backend: NestJS + MongoDB auth API

See the [root README](../README.md) for setup, the API table, and security notes.

```bash
cp .env.example .env && npm install && npm run start:dev   # http://localhost:3000/api/docs
npm test           # unit tests
npm run test:e2e   # HTTP e2e tests (in-memory DB; DB_DRIVER=mongo MONGODB_URI=... for real MongoDB)
```
